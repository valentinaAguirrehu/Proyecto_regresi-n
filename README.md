# Proyecto regresión lineal (Flask + Vercel)
- `Regresion_Lineal_CRISP-DM.ipynb`: cuaderno para Google Colab (limpieza, modelos, gráficas, exportación).
- `app.py`: interfaz web (Flask).
- `modelos/`: `.pkl` exportados + `config.json` que usa la web.
- `graficas/`: imágenes para el informe.
Probar local: `pip install flask` y `python app.py`.
